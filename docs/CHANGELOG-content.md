# Content changelog — bundle milestones

> Split out of `AGENTS.md` §5 (checklist v10). The current content **rules** live in
> [`docs/content-pipeline.md`](content-pipeline.md); this file is only the record of which
> `contentVersion` bump shipped what. The one-shot batches that applied each change are
> catalogued in [`scripts/archive/README.md`](../scripts/archive/README.md) — **never re-run one.**

Every content change bumps `contentVersion` **identically in all five** JSON files
(`lessons`, `vocabulary`, `exercises`, `placement`, `knowledge`); the current bundle is **35**.

| **34 → 35** | **Longer conversations at A2 and above.** A four-turn exchange is one opening, one middle and one close: enough to prove a reply, not enough to feel like a conversation. Every lesson at A2–C2 gained one or two more turns — five or six in total across 58 lessons, +90 turns — that continue the same exchange in the same place with the same person: the second half of the hotel booking, the plumber's visit arranged for the morning, a statistic challenged, a concession invited after the argument. A1 stays at four: its replies are single clauses, and a longer scene would repeat the same structure instead of extending it. The new turns inherit `sceneFa` / `partnerFa` from the lesson's first turn, so the role cannot drift mid-dialogue, and the batch refuses to write an answer with a digit, a proper noun inside the sentence or an echo of the question. 1283 → 1373 exercises, 380 → 470 speaking turns; lessons, words and knowledge items unchanged | `v35_dialogue_extend.mjs` (+ `v35_dialogue_data_1.mjs`, `v35_dialogue_data_2.mjs`) |
